# Wan 2.7 AI Video & Image Generator — Interactive Prompt Studio & MCP Hub

Welcome to the official interactive companion Space for **[Wan 2.7 AI](https://wan2-7.io/)** (`wan2-7.io`). Build structured text-to-video, image-to-video, and image generation prompts, estimate account credit costs, and generate ready-to-copy configurations for the **[Wan 2.7 MCP Server](https://wan2-7.io/mcp/)** and **[Wan 2.7 CLI](https://wan2-7.io/cli/)**.

## Supported Models

| Model ID | Modality | Resolutions | Aspect Ratios | Description |
|---|---|---|---|---|
| `wan2.7-t2v` | Text-to-Video | `720p`, `1080p` | `16:9`, `9:16`, `1:1` | Cinematic camera control, natural motion physics, 5s–10s duration |
| `wan2.7-i2v` | Image-to-Video | `720p`, `1080p` | `16:9`, `9:16`, `1:1` | First-frame faithful animation with temporal consistency |
| `wan2.7-image` | Text-to-Image | `1080p`, `2K` | `1:1`, `16:9`, `9:16`, `4:3`, `3:4` | High-speed photorealistic and stylized keyframe generation |
| `wan2.7-image-pro` | Text-to-Image Pro | `2K`, `4K` | `1:1`, `16:9`, `9:16`, `4:3`, `3:4` | Studio-grade typography, complex lighting, and multi-subject composition |
